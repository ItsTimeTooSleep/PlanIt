## 各维度详解

### 1. 名称相似度 (nameSimilarity)

#### 计算逻辑
```
相似任务数 = 包含当前任务标题 或 被当前任务标题包含的历史任务数
相似度 = min(1, 相似任务数 / max(总任务数, 1))
```

#### 取值范围
- **最小值**：0（没有相似任务）
- **最大值**：1（所有任务都相似）

#### 实际意义
- 衡量任务的常见程度
- 相似度越高，表示用户越常做这类任务
- 对于新类型或不常见的任务，得分较低

#### 示例
- 用户历史中有 50 个任务，其中 10 个包含"学习"
- 当前任务标题为"数学学习"
- 相似度 = min(1, 10 / 50) = 0.2

---

### 2. 时间模式 (timePattern)

#### 计算逻辑
```
如果没有开始时间：返回 0.3

任务小时 = 任务开始时间的小时部分
小时差 = |任务小时 - 当前小时|
得分 = max(0, 1 - 小时差 / 6)
```

#### 取值范围
- **最小值**：0（时间差 ≥ 6 小时）
- **最大值**：1（时间完全相同）
- **无开始时间**：0.3

#### 实际意义
- 衡量任务时间与当前时间的匹配程度
- 时间越接近，得分越高
- 超过 6 小时差异，得分为 0

#### 示例
- 当前时间：14:00（下午 2 点）
- 任务开始时间：16:00（下午 4 点）
- 小时差 = 2
- 得分 = 1 - 2 / 6 ≈ 0.667

---

### 3. 标签关联 (tagCorrelation)

#### 计算逻辑
```
如果没有标签：返回 0.3

基础得分 = 0.3
对于每个标签：
  标签计数 = 使用该标签的历史任务数
  标签比例 = 标签计数 / max(总任务数, 1)
  得分 += 标签比例 × 0.2

最终得分 = min(1, 得分)
```

#### 取值范围
- **最小值**：0.3（无标签）
- **最大值**：1

#### 实际意义
- 衡量标签的常见程度
- 标签越常用，得分越高
- 多个标签可叠加加分，但不超过 1

#### 示例
- 总任务数：100
- 任务标签：["学习", "工作"]
- "学习"标签计数：40，"工作"标签计数：30
- 得分 = 0.3 + (40/100)×0.2 + (30/100)×0.2 = 0.3 + 0.08 + 0.06 = 0.44

---

### 4. 时长统计 (durationStats)

#### 计算逻辑
```
相似时长任务数 = 时长相差 < 30 分钟的历史任务数
得分 = min(1, 相似时长任务数 / max(总任务数, 10))
```

#### 取值范围
- **最小值**：0
- **最大值**：1

#### 实际意义
- 衡量任务时长的常见程度
- 与历史任务时长越接近，得分越高
- 以 30 分钟为容差范围

#### 示例
- 总任务数：20
- 当前任务时长：60 分钟
- 时长在 30-90 分钟之间的任务数：12
- 得分 = min(1, 12 / 10) = 1

### 7. 时间关系 (timeRelation)

#### 计算逻辑
由 `TimeRelationAnalyzer.calculateTimeRelationScore` 计算：

```
如果没有时间关系模式：返回 0.3

得分 = 0
如果有计划日期和截止日期：
  计划到截止天数 = 截止日期 - 计划日期
  偏差 = |计划到截止天数 - 历史平均计划到截止天数|
  得分 += max(0, 1 - 偏差 / max(历史平均计划到截止天数, 7)) × 0.4

如果有开始时间：
  小时偏差 = |任务小时 - 当前小时|
  得分 += max(0, 1 - 小时偏差 / 6) × 0.3

如果有计划日期：
  星期匹配 = (任务星期 == 当前星期) ? 0.3 : 0.15
  得分 += 星期匹配

最终得分 = min(1, 得分)
```

#### 取值范围
- **最小值**：0.3
- **最大值**：1

#### 实际意义
- 综合衡量时间关系的合理性
- 包含截止日期偏差、时间匹配、星期匹配三个子维度
- 基于历史学习的平均模式

---

### 8. 行为预测 (behaviorPrediction)

#### 计算逻辑
由 `BehaviorPredictor.calculateBehaviorPredictionScore` 计算：

```
基础得分 = 0.3

如果有开始时间：
  匹配窗口 = 找到任务小时所在的创建时间窗口
  如果找到：
    最大频率 = 所有窗口的最大频率
    得分 += 0.3 × (匹配窗口频率 / max(最大频率, 1))

如果有标签：
  标签组合键 = 标签排序后连接
  匹配组合 = 找到相同的标签组合
  如果找到：
    最大组合频率 = 所有组合的最大频率
    得分 += 0.4 × (匹配组合频率 / max(最大组合频率, 1))

最终得分 = min(1, 得分)
```

#### 取值范围
- **最小值**：0.3
- **最大值**：1

#### 实际意义
- 基于用户行为模式的预测得分
- 考虑创建时间窗口和标签组合模式
- 越符合用户历史行为习惯，得分越高

---

### 9. 周期性 (periodicPattern)

#### 计算逻辑
由 `PeriodicTaskDetector.calculatePeriodicScore` 计算：

```
如果没有周期性模式：返回 0.3

基础标题 = 规范化的任务标题（去除数字编号）
匹配模式 = 找到标题模式匹配的周期性模式

如果找到匹配模式：
  得分 = 0.5 + 模式置信度 × 0.5
否则：
  得分 = 0.3
```

#### 取值范围
- **最小值**：0.3
- **最大值**：1（当模式置信度为 1 时）

#### 实际意义
- 衡量任务的周期性特征
- 识别日、周、月周期的任务
- 周期性越强、置信度越高，得分越高

#### 示例
- 任务标题："每周运动 #3"
- 规范化标题："每周运动"
- 匹配到周周期模式，置信度 0.8
- 得分 = 0.5 + 0.8 × 0.5 = 0.9

---

### 10. 上下文适配 (contextAdaptation)

#### 计算逻辑
```
基础得分 = 0.5

第一步：统计历史数据中各标签的时间模式
  对于每个历史任务的每个标签：
    记录该标签在各时间段（早晨/下午/晚上/夜间）的出现次数
    记录该标签在各日期类型（工作日/周末）的出现次数

第二步：根据当前上下文计算得分
  对于当前任务的每个标签：
    如果有该标签的统计数据：
      时间段比例 = 当前时间段的出现次数 / 该标签总出现次数
      得分 += 时间段比例 × 0.15
      
      日期类型比例 = 当前日期类型的出现次数 / 该标签总出现次数
      得分 += 日期类型比例 × 0.15

最终得分 = min(1, 得分)
```

#### 取值范围
- **最小值**：0.5
- **最大值**：1

#### 实际意义
- 基于历史数据学习标签的时间偏好
- 例如：用户可能习惯在工作日早晨学习，周末晚上休息
- 当前上下文与标签历史模式越匹配，得分越高

#### 时间段定义
- **早晨**：6:00 - 12:00
- **下午**：12:00 - 17:00
- **晚上**：17:00 - 21:00
- **夜间**：21:00 - 6:00

#### 日期类型定义
- **工作日**：周一至周五（1-5）
- **周末**：周六、周日（0, 6）

## 权重配置

### 默认权重
```typescript
{
  nameSimilarity: 0.12,      // 名称相似度
  timePattern: 0.12,         // 时间模式
  tagCorrelation: 0.12,      // 标签关联
  durationStats: 0.10,       // 时长统计
  schedulingPattern: 0.10,   // 调度模式
  dueDatePattern: 0.10,      // 截止日期
  timeRelation: 0.12,        // 时间关系
  behaviorPrediction: 0.10,  // 行为预测
  periodicPattern: 0.10,     // 周期性
  contextAdaptation: 0.12,   // 上下文适配
}
```

### 权重特点
- 各维度权重相对均衡
- 名称相似度、时间模式、时间关系、上下文适配权重略高（0.12）
- 预留维度（调度模式、截止日期）也分配了权重（0.10）
- 总权重和为 1.0

### 权重调整
通过 `SelfLearningMechanism` 根据用户反馈自动调整：
- 接受反馈：增加高分维度的权重
- 拒绝反馈：减少高分维度的权重
- 权重范围限制：0.05 - 0.2

## 评分计算流程

### 完整计算步骤
1. 分别计算 10 个维度的得分
2. 将各维度得分乘以对应权重
3. 求和得到总分
4. 保留 3 位小数

### 公式
```
总分 = (名称相似度 × 0.12) +
       (时间模式 × 0.12) +
       (标签关联 × 0.12) +
       (时长统计 × 0.10) +
       (调度模式 × 0.10) +
       (截止日期 × 0.10) +
       (时间关系 × 0.12) +
       (行为预测 × 0.10) +
       (周期性 × 0.10) +
       (上下文适配 × 0.12)
```

### 计算示例

假设某任务的各维度得分如下：
- 名称相似度：0.6
- 时间模式：0.8
- 标签关联：0.5
- 时长统计：0.4
- 调度模式：0.5
- 截止日期：0.5
- 时间关系：0.7
- 行为预测：0.6
- 周期性：0.9
- 上下文适配：0.8

计算总分：
```
总分 = (0.6 × 0.12) + (0.8 × 0.12) + (0.5 × 0.12) +
       (0.4 × 0.10) + (0.5 × 0.10) + (0.5 × 0.10) +
       (0.7 × 0.12) + (0.6 × 0.10) + (0.9 × 0.10) +
       (0.8 × 0.12)
     = 0.072 + 0.096 + 0.06 +
       0.04 + 0.05 + 0.05 +
       0.084 + 0.06 + 0.09 +
       0.096
     = 0.702
```

## 置信度与推荐

### 置信度计算
置信度 = 总分 × 重复惩罚系数

重复惩罚：
- 完全时间冲突：0（直接排除）
- 同日期同标题：0.6
- 其他：1

### 推荐过滤
- 最小置信度阈值：0.35
- 低于阈值的推荐被过滤
- 强信号（周期性、时间关系、上下文适配、行为预测任一维度高分）可降低要求

### 最终排序
推荐按置信度降序排序，取前 N 个（默认 8 个）
