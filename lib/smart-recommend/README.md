## 系统概述

PlanIt 智能推荐引擎是一个基于用户行为分析的任务推荐系统，通过分析历史任务数据、识别周期性模式、学习用户行为偏好，为用户提供智能、个性化的任务建议。

### 主要特性

- **混合推荐策略**：结合历史任务复现、周期性模式预测、上下文适配等多种方法
- **多维度评分**：从名称相似度、时间模式、标签关联、周期性等 10 个维度进行综合评分
- **自学习机制**：根据用户反馈自动调整权重，不断优化推荐质量
- **上下文感知**：根据当前时间、工作日/周末等上下文信息动态调整推荐
- **周期性检测**：自动识别日、周、月周期的任务模式

## 核心组件

### 推荐类型

系统支持三种主要的推荐类型：

1. **历史推荐**：基于用户历史任务进行复现和优化
2. **预测推荐**：基于检测到的周期性模式预测未来任务
3. **探索推荐**：（已禁用）探索新的任务类型

### 评分维度

推荐结果通过以下 10 个维度进行评分：

1. **名称相似度**：与历史任务标题的相似程度
2. **时间模式**：与当前时间的匹配程度
3. **标签关联**：标签在历史数据中的常见程度
4. **时长统计**：任务时长的匹配度
5. **调度模式**：任务安排的历史模式
6. **截止日期**：截止日期的历史模式
7. **时间关系**：创建、计划、截止之间的时间关系
8. **行为预测**：用户行为模式的匹配程度
9. **周期性**：任务的周期性特征
10. **上下文适配**：与当前上下文（时间、工作日等）的适配程度

## 推荐算法

### 推荐流程

1. **上下文生成**：分析当前时间、工作日/周末、近期任务等信息
2. **模式分析**：运行各分析器获取时间关系、周期性、行为模式
3. **推荐生成**：生成历史推荐、预测推荐
4. **后处理**：去重、过滤、排序、截断
5. **决策日志**：记录完整的决策过程

### 评分计算

每个推荐项的综合评分通过加权平均计算：

`总分 = Σ(维度评分 × 维度权重)`

默认权重配置下，各维度权重在 0.10-0.12 之间，保持相对均衡。

### 置信度过滤

- 最小置信度阈值：0.35
- 低于阈值的推荐会被过滤
- 强信号检测：周期性、时间关系、上下文适配、行为预测任一维度 > 0.5/0.6 可降低置信度要求

### 去重机制

- 基于标题、日期、开始时间、推荐类型组合键去重
- 保留置信度最高的推荐项
- 检测完全时间冲突的任务并排除

## 分析器模块

### 1. 时间关系分析器 (TimeRelationAnalyzer)

#### 功能
分析任务创建、计划、截止之间的时间关系模式。

#### 分析内容
- 创建到计划的平均提前天数
- 计划到截止的平均提前天数
- 创建到截止的平均提前天数
- 时间段分布（小时级）
- 星期分布

#### 评分逻辑
- 截止日期偏差：与历史平均提前天数的偏差越小，得分越高
- 时间匹配：与当前小时越接近，得分越高
- 星期匹配：与当前星期相同加分

### 2. 周期性任务检测器 (PeriodicTaskDetector)

#### 功能
从历史任务中识别日、周、月周期的任务模式。

#### 检测逻辑

**日周期**：
- 相同/相似标题任务出现 ≥ 3 次
- 同一时间段出现频率 ≥ 60%
- 记录最频繁的开始时间

**周周期**：
- 相同/相似标题任务出现 ≥ 3 次
- 同一星期几出现频率 ≥ 50%
- 记录最频繁的星期几

**月周期**：
- 相同/相似标题任务出现 ≥ 3 次
- 同一日期出现频率 ≥ 50%
- 记录最频繁的日期

#### 预测生成
根据识别的周期模式预测下一次出现时间。

### 3. 行为预测器 (BehaviorPredictor)

#### 功能
分析用户的任务创建行为模式。

#### 分析内容
- **创建时间窗口**：统计各 2 小时时段的任务创建频率
- **截止日期提前量**：按标签统计截止日期相对于计划日期的平均提前天数
- **标签组合**：统计常见的标签组合及其出现频率

#### 预测功能
- 预测任务的截止日期
- 预测任务的最佳开始/结束时间

## 引擎模块

### 1. 混合推荐引擎 (HybridRecommendationEngine)

#### 核心功能
整合各分析器，生成最终推荐列表。

#### 主要步骤

1. **历史推荐生成**
   - 从历史任务中去重（按规范化标题）
   - 计算各维度评分
   - 增强任务信息（预测日期、时间、截止日期）
   - 应用重复惩罚

2. **预测推荐生成**
   - 基于周期性模式生成预测任务
   - 要求周期性模式置信度 ≥ 0.5

3. **后处理**
   - 去重
   - 合理性检查（置信度、日期、无重复、时间未过期）
   - 按置信度降序排序
   - 取前 N 个（默认 8 个）

#### 上下文增强
- 自动调整任务到未来时间槽
- 从历史数据学习标签的时间模式
- 根据当前时间和工作日/周末动态调整

### 2. 动态规则生成器 (DynamicRuleGenerator)

#### 功能
从历史数据中生成推荐规则，并根据使用反馈调整规则置信度。

#### 规则类型

1. **时间规则**
   - 分析早晨（6-12点）最常用的标签
   - 使用率 > 30% 时生成规则

2. **标签组合规则**
   - 统计标签对共同出现的频率
   - 共同出现 ≥ 3 次时生成规则

#### 规则更新
- 成功使用：置信度 + 0.05（上限 0.95）
- 失败使用：置信度 - 0.03（下限 0.1）

## 评估与学习

### 1. 评估引擎 (EvaluationEngine)

#### 评估指标
- **接受率**：用户接受的推荐比例
- **精确率/召回率/F1**：基于接受率计算
- **任务完成率**：接受率 × 0.8
- **平均置信度**：所有推荐的平均总分
- **新颖性得分**：低相似度推荐的接受率
- **适应速度**：趋势变化的速率
- **趋势分析**：比较前半/后半反馈的接受率变化

#### 趋势判断
- 改进：接受率提升 > 0.1
- 下降：接受率下降 > 0.1
- 稳定：其他情况

### 2. 自学习机制 (SelfLearningMechanism)

#### 权重调整逻辑
- **接受反馈**：增加高分维度的权重
- **拒绝反馈**：减少高分维度的权重
- **权重范围**：0.05 - 0.2
- **归一化**：调整后权重总和归一化为 1

#### 学习率
默认学习率：0.05

#### 偏好漂移检测
比较最近反馈的前半和后半的平均总分差异，检测用户偏好变化。

## 状态管理

### 存储结构

系统状态包含以下数据：

- **任务数据**：历史任务列表
- **标签数据**：可用标签列表
- **算法配置**：权重、阈值等配置
- **决策日志**：推荐决策过程记录
- **反馈记录**：用户对推荐的反馈
- **调度模式**：学习到的调度模式
- **自定义创建时间**：（可选）

### 持久化

- 使用 `localStorage` 存储
- 存储键：`planit_smart_recommend`
- 版本控制：支持数据迁移
- 数据验证：加载时验证各字段格式

### 默认配置

```
- 最大推荐数：8
- 最小置信度：0.15
- 时间窗口小时：2
- 学习率：0.05
- 新颖性阈值：0.3
- 探索率：0.25
- 适应速度：0.1
```

## 使用指南

### 基本使用

```typescript
import {
  HybridRecommendationEngine,
  EvaluationEngine,
  SelfLearningMechanism,
  loadState,
  saveState,
} from "@/lib/smart-recommend";

// 1. 加载状态
const state = loadState();

// 2. 创建推荐引擎
const engine = new HybridRecommendationEngine(
  state.tasks,
  state.tags,
  state.config
);

// 3. 生成推荐
const { recommendations, analysisMetadata, log } = engine.generateRecommendations();

// 4. 处理用户反馈
// ... 用户接受或拒绝推荐 ...
const feedback: FeedbackRecord = {
  id: generateId(),
  recommendationId: recommendations[0].task.id,
  taskTitle: recommendations[0].task.title,
  accepted: true, // 或 false
  timestamp: new Date().toISOString(),
  scores: recommendations[0].scores,
  contextTime: new Date().toISOString(),
  task: recommendations[0].task,
};

// 5. 更新学习
const learner = new SelfLearningMechanism(state.config);
state.config = learner.updateFromFeedback(feedback);

// 6. 保存状态
state.feedbacks.push(feedback);
state.logs.push(log);
saveState(state);

// 7. 评估系统
const evaluator = new EvaluationEngine(state.feedbacks);
const metrics = evaluator.calculateMetrics();
```

### 快捷函数

系统也提供快捷函数简化使用：

```typescript
import { generateRecommendations, calculateAccuracy } from "@/lib/smart-recommend";

// 生成推荐
const result = generateRecommendations(tasks, tags, config, contextTime);

// 计算准确率
const accuracy = calculateAccuracy(feedbacks);
```

系统预置了 8 个常用标签：
- 学习
- 运动
- 休息
- 社交
- 工作
- 创作

### 推荐结果解读

每个推荐项包含：
- `task`：推荐的任务详情
- `scores`：各维度评分详情
- `confidence`：综合置信度（0-1）
- `reason`：推荐理由说明
- `recommendationType`：推荐类型（historical/predicted）

## 最佳实践

1. **数据积累**：建议至少积累 10-20 个历史任务以获得较好效果
2. **反馈收集**：鼓励用户对推荐进行反馈，加速学习过程
3. **定期评估**：定期查看评估指标，了解推荐质量变化
4. **标签使用**：合理使用标签，帮助系统更好地理解任务类型
5. **时间记录**：尽量记录任务的开始时间和截止日期，提高模式识别准确性
